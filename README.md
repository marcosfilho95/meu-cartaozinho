# Meu Cartãozinho

Criei o **Meu Cartãozinho** para organizar melhor minha vida financeira, acompanhar meus gastos e planejar meus objetivos com mais clareza.

🔗 **Acesse o projeto:** https://meucartaozinho.lovable.app/

## Objetivo

A ideia é funcionar como uma **planilha financeira inteligente**, mas de forma mais prática, visual e automatizada.

A aplicação reúne recursos para:

- acompanhar receitas e despesas;
- visualizar a evolução dos gastos;
- comparar períodos;
- organizar o orçamento;
- definir metas e objetivos financeiros;
- facilitar o planejamento financeiro por meio de gráficos e automações.

O projeto foi criado inicialmente para atender uma necessidade pessoal, mas também pode ser utilizado por outras pessoas que buscam **mais organização, planejamento e qualidade de vida financeira**.

## Instalação no celular — PWA

O **Meu Cartãozinho** pode ser instalado no celular e utilizado como um aplicativo.

### 🤖 Android — Chrome

1. Abra o link da aplicação no **Google Chrome**.
2. Toque no menu de **três pontos** no canto superior direito.
3. Selecione **Instalar app** ou **Adicionar à tela inicial**.
4. Confirme em **Instalar**.

### 🍎 iPhone — Safari

1. Abra o link da aplicação no **Safari**.
2. Toque no botão **Compartilhar**.
3. Role para baixo e selecione **Adicionar à Tela de Início**.
4. Confirme em **Adicionar**.
